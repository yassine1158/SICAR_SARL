Espace administration

Connectez-vous avec votre jeton GitHub (accès « Contents : Read and write » sur le dépôt du site).

Comment obtenir un jeton ?
  1. GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. Repository access : Only select repositories → choisir le dépôt du site.
  3. Permissions → Contents : Read and write.
  4. Générer, copier le jeton et le coller ici.
